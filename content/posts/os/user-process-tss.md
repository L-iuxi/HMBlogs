## TSS 任务状态段

单核 CPU 要想实现多任务，唯一的方案就是多个任务共享同一个 CPU，让所有任务轮流使用。

TSS（Task Status Segment）是程序员为任务单独定义的一个结构体变量。CPU 通过 TSS 保存和恢复任务的上下文（寄存器状态、栈指针等），从而实现任务切换。

## 用户进程

用户进程 = 运行在 CPU 用户态（Ring3）的程序，它有三条限制：

1. **不能随便访问硬件** — 所有硬件操作必须通过内核代理
2. **不能随便访问内核内存** — 用户空间和内核空间隔离
3. **只能通过中断 / 系统调用请求内核帮忙干活**

这种隔离保证了即使某个用户进程崩溃，也不会影响整个系统的稳定性。
