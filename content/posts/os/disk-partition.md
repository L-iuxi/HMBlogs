## 创建磁盘镜像

使用 bochs 自带的 `bximage` 工具创建磁盘：

```bash
bin/bximage
```

按提示依次输入：`1` → `hd` → `flat` → `80` → `hd80M.img`

在 `bochsrc.disk` 中配置：

```
ata0-slave: type=disk, path="hd80M.img", mode=flat, cylinders=162, heads=16, spt=63
```

这样 bochs 虚拟机启动时就会识别并自动挂载这个磁盘。

## 分区操作

使用 fdisk 工具对磁盘进行分区：

```bash
fdisk ./hd80M.img
```

### 分区类型

| 类型 | 说明 |
|------|------|
| 主分区 | 最多 4 个，可直接存储数据 |
| 扩展分区 | 最多 1 个，作为逻辑分区的容器 |
| 逻辑分区 | 在扩展分区内创建，突破 4 个分区限制 |

分区的本质，就是将多个连续的柱面划分为一个区域。最初磁盘只支持最多分 4 个区。后来由于需求增加，磁盘需要支持能分更多区，同时又为了能够兼容旧有的最多支持 4 个分区，就发明了扩展分区。扩展分区并不直接用于存储数据，而是作为一个容器，可以在其中创建多个逻辑分区。一个磁盘，最多一个扩展分区。

### CHS 与扇区计算

磁盘参数 CHS = Cylinders（柱面）/ Heads（磁头）/ Sectors（每磁道扇区数）。

创建 `hd80M.img` 时会提示 `Creating hard disk image 'hd80M.img' with CHS=162/16/63`，意思是柱面 162 个，磁头 16 个，每个磁道 63 个扇区。

扇区号计算公式：`结束扇区 = (结束柱面 + 1) × 磁头数 × 每道扇区数 - 1`（-1 是因为扇区从 0 开始编号）。

### 关键扇区计算说明

- **主分区 1 起始扇区 2048**：作者的 1 分区起始柱面是 1，计算得起始扇区应该是 `63 × 16 = 1008`。但由于 fdisk 工具指定第一个分区最小起始扇区为 2048，所以只能设定 1 分区起始扇区为 2048。
- **主分区 1 结束扇区 33263**：作者指定 1 分区结束柱面为 32，计算得结束扇区为 `(32 + 1) × 16 × 63 - 1 = 33263`。
- 逻辑分区 5～9 的结束扇区同理，分别对应结束柱面 50、75、90、120，最后一个逻辑分区 9 直接延伸到磁盘末尾。

### 分区类型 ID

使用 fdisk 的 `t` 命令修改分区类型 ID，例如 `0x66` 表示自定义文件系统类型。
